Panduan Mengaktifkan AI

Ada dua cara. Cukup pilih salah satu — keduanya mengaktifkan semua fitur AI (pembahasan, tutor, variasi soal, dan scan foto).

Cara 1 — Gemini (gratis, paling mudah)
  1. Buka aistudio.google.com/apikey lalu login dengan akun Google.
  2. Klik tombol Create API key, lalu salin kuncinya.
  3. Tempel di kolom API key paling atas, klik Simpan lalu Test. Selesai!
Cara 2 — Provider kustom (opsional, contoh: Groq)
  1. Buka console.groq.com/keys lalu daftar gratis (bisa pakai akun Google).
  2. Klik Create API Key, lalu salin kuncinya.
  3. Tempel kunci itu di kolom API key provider — alamat servernya terisi otomatis (kalau tidak, lihat contoh di kolom Base URL).
  4. Klik Cek Daftar Model, lalu ketuk salah satu nama di daftar untuk mengisi kolom Model teks.
  5. Klik Simpan Provider. Selesai!

Kolom Model Vision boleh dibiarkan kosong — scan foto otomatis memakai Gemini. Isi hanya kalau ingin scan lewat provider ini juga, memakai model yang bisa membaca gambar (biasanya bertanda vision atau vl).

Data & Privasi

Semua soal, catatan, riwayat, dan progres tersimpan hanya di perangkat ini. Exambre tidak memiliki akun, server, atau sinkronisasi otomatis, dan tidak memasang pelacakan atau iklan.

Fitur AI bersifat opsional: teks atau foto yang kamu pilih akan dikirim ke provider AI yang kamu atur sendiri (Gemini atau provider kustom). Kunci API disimpan lokal di perangkat dan tidak pernah dikirim ke pembuat Exambre.

Menghapus app atau membersihkan data browser ikut menghapus datamu. Lakukan Export Data secara berkala untuk menjaga backup.

AI Penjelasan

Mulai cepat (Gemini, gratis): 1) Buka aistudio.google.com/apikey → klik "Create API key". 2) Salin key-nya. 3) Tempel di bawah lalu Simpan. Tanpa key, fitur AI (scan soal, tutor, variasi, analisis) tidak aktif — SRS & latihan tetap jalan normal.

Pakai Groq, OpenRouter, Cerebras, atau Ollama lokal. Kosongkan = kembali ke Gemini.

Model terpisah untuk scan foto — model teks umumnya tidak bisa membaca gambar. Biarkan kosong kalau tidak mau foto soal dikirim ke provider ini.
